Personality-aware Cross-Domain Recommendation System

AI-powered cross-domain recommendation system that predicts user game preferences from book ratings using transformer-based semantic embeddings, personality-aware profiling, and vector similarity search.

🚀 Overview

This project implements a Personality-aware Cross-Domain Recommendation System that recommends games based on users’ book preferences. The system combines Natural Language Processing (NLP), transformer-based embeddings, and vector similarity search to generate highly personalized recommendations across domains.

The model analyzes:

User book ratings
Semantic similarity between books and games
Personality-aware preference patterns
Embedding-based behavioral matching

to recommend games that align with user interests.

✨ Features
✅ Cross-domain recommendation (Books → Games)
✅ Transformer-based semantic embeddings
✅ Personality-aware user profiling
✅ High-speed vector similarity search using FAISS
✅ End-to-end recommendation pipeline
✅ Ranking evaluation metrics

✅ Scalable embedding-based recommendation engine
